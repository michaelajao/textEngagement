# Writing Engagement as a Behavioural Marker of Retention

Retrospective cohort study examining whether participant writing, facilitator
comments, peer forums, and platform browsing are associated with programme
completion in the Hope Programme digital health intervention.

## Canonical Analysis Pipeline

The production pipeline is the source of truth for the manuscript and generated
results:

1. `src/dataset.py`
2. `src/features.py`
3. `python -m src.analysis.run_all`

There is no notebook layer. The exploratory notebooks were removed once their
saved outputs had drifted from the pipeline (earlier sample sizes and feature
counts); they remain in git history if ever needed. `src/` is the only source of
truth for the manuscript.

## Pipeline

The analysis runs in three layers:

1. **Layer 1 — Data Parsing** (`src/dataset.py`):
   Converts platform JSON exports into flat CSVs, including users, activities,
   facilitator comments, discussions, page visits, user profiles, and SWEMWBS
   survey entries when present.

   ```bash
   python src/dataset.py --exclude-demo
   ```

2. **Layer 2 — Feature Engineering** (`src/features.py`):
   Computes 33 engagement features across platform engagement, writing,
   facilitator interaction, forum participation, and early-warning dimensions
   (near-duplicate features are excluded after a redundancy audit).
   It also derives separate exploratory profile and SWEMWBS features that are
   excluded from the main 33-feature engagement set.

   ```bash
   python src/features.py
   python src/features.py --skip-nlp   # reuse existing NLP features
   ```

3. **Layer 3 — Analysis** (`src/analysis/run_all.py`):
   Runs all statistical analyses (Mann-Whitney, logistic regression, GEE,
   survival analysis, engagement milestone prevalence, temporal trajectories,
   K-means clustering, SWEMWBS exploratory analyses, and robustness checks) and
   generates figures/tables.

   ```bash
   python -m src.analysis.run_all
   ```

## Key Dependencies

| Package | Purpose |
|---------|---------|
| pandas, numpy, scipy | Data manipulation and statistical tests |
| statsmodels | GEE, logistic regression |
| scikit-learn | K-means clustering, cross-validation |
| lifelines | Kaplan-Meier survival analysis, Cox PH |
| transformers, torch | RoBERTa sentiment, BART zero-shot topics |
| matplotlib | Publication-quality figures |
| python-docx | Manuscript build only (see below) |

Building the Word version of the supplementary appendices additionally requires
**pandoc** on `PATH`, which is not a pip package:

```bash
cd doc && python build_multimedia_appendices_docx.py
```

The two framework schematics (Figures 1 and 2) illustrate the study design rather
than reporting data, so they are TikZ manuscript assets rather than pipeline
outputs. They need **pdflatex** and **PyMuPDF**:

```bash
cd doc && python build_figures.py
```

Every other figure is produced from the data by `python -m src.analysis.run_all`.

Call the script rather than pandoc directly — it repairs the longtable continuation
rows, `\clearpage` handling, `p{}` column widths and caption numbering that a plain
pandoc run renders incorrectly.

`doc/` is not tracked in git. The manuscript, appendices, slides and bibliography
live there locally and are versioned outside this repository.

## Research Questions

- **RQ1**: Are early writing behaviours associated with programme completion?
- **RQ2**: Is facilitator comment receipt associated with retention, and does comment quality matter?
- **RQ3**: Is forum participation independently associated with completion?
- **RQ4**: Are optional profile-completion fields engagement markers beyond observed behaviour?
- **RQ5**: How does writing engagement relate to optional SWEMWBS wellbeing change?

The machine-learning prediction work for early dropout or weekly dropout is a
separate follow-on paper. This repository establishes the retrospective cohort
features, associations, profiles, and temporal signals that can inform that later
modelling work.

## Observation Unit

Each observation is a `(module_id, user_id, cohort_id)` enrolment.
Participants may appear in multiple cohorts or modules.
